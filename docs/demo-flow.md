# Demo flow

Design from what is proven to work. Keep a manual or prerecorded-safe fallback only if rules permit it.

This sequence uses only simulator capabilities actually documented in the Integration Guide (no fabricated features).

**Total target runtime:** ~12–15 minutes, leaving room for Q&A within a typical judging slot.

## Setup checklist
- Simulator container started fresh (`/admin/reset` if reused from a prior rehearsal) and health-checked (`/v1/health`) before judges arrive.
- Internet dependency: none required for the core loop; confirm before the demo whether a GenAI explanation feature (if built) needs a live API key/connection, and have a non-LLM fallback explanation ready regardless (see `docs/cut-list.md`).
- Event/fault injection payloads for steps 2, 7, 9 pre-scripted and dry-run at least once end-to-end.
- Backup path (curl/Swagger UI/pre-recorded run) complies with event rules — no fabricated results presented as live.
- Total timing and step-transition ownership rehearsed with whoever is narrating vs. driving the keyboard.
